### Under the hood

<sub>How the flagship systems are put together, at a high level. Click to expand.</sub>

<details>
<summary><b>Terravive</b>: multi-tenant RAG with a guarded agent loop</summary>
<br/>

```mermaid
flowchart TB
  W["Next.js web<br/>typed OpenAPI client"] --> G["NestJS API<br/>JWT · OAuth · RBAC guards"]
  G --> T["Tenant resolver<br/>subdomain → tenant context"]

  subgraph ING["Ingestion · BullMQ workers"]
    D["Tenant documents · CAD · geo · imagery · audio"] --> P["Parse · OCR · vision extraction"]
    PUB["Public geospatial & ecological data sources"] --> P
    P --> C["Chunk"] --> E["Multimodal embeddings"]
  end

  T --> D
  E --> V[("PostgreSQL + pgvector + full-text<br/>row-level security per tenant")]

  subgraph AG["LangGraph agent"]
    IG["Input guard"] --> PL["Planner"] --> TL["Tools"] --> RS["Respond"] --> OG["Grounding guard"]
  end

  T --> IG
  TL --> R["Hybrid retrieval<br/>vector + keyword → RRF → rerank"] --> V
  RS --> L["Claude · fallback providers<br/>circuit breaker + budgets"]
  OG --> S["Cited answer streamed over SSE"] --> W
```

**Highlights:** tenant isolation enforced twice (repository scoping + Postgres RLS) · hybrid retrieval with reranking · rules-first guardrails · OpenTelemetry tracing · retrieval-quality evals in CI.

</details>

<details>
<summary><b>SiftSight</b>: recruitment platform with an event-driven AI service</summary>
<br/>

```mermaid
flowchart TB
  U["Candidates · Recruiters · Admins"] --> FE["Next.js dashboards"]
  FE -->|"GraphQL + WebSockets"| API["NestJS GraphQL API<br/>JWT · OAuth · 2FA · RBAC"]

  API --> DOM["Pipelines (Kanban) · assessments · chat & meetings · notifications"]
  API --> DB[("PostgreSQL + PostGIS")]
  API --> RD[("Redis")]
  API --> S3[("S3")]

  API -->|"SQS jobs"| AI["Python AI service"]
  AI --> M["Resume parsing · embedding-based ranking<br/>question generation · answer grading · transcription"]
  AI -->|"result webhooks"| API

  API --> X["Stripe subscriptions · identity verification<br/>e-signature · calendar & meetings"]
```

**Highlights:** async AI workloads over a queue, decoupled from the API · GraphQL end to end with codegen · CI/CD with automatic rollback.

</details>

<details>
<summary><b>Kynos</b>: contract-first modular monolith with a governed AI guide</summary>
<br/>

```mermaid
flowchart TB
  M["Members"] --> WC["Next.js member app"]
  OP["Operators"] --> WA["Next.js admin console"]
  CT["Content team"] --> WO["Next.js Content OS"]
  WC & WA & WO --> API["NestJS modular monolith<br/>Zod contracts between modules"]

  API --> FW["Guided programmes · journal · practices · journey"]
  API --> G["AI Guide · chat + voice + tool calls"]
  G --> GW["LLM gateway<br/>budgets · claims linting · tracing"] --> CL["Claude"]

  API --> DB[("PostgreSQL + pgvector<br/>schema per module · RLS")]
  API -->|"transactional outbox"| WK["Workers · rollups · nudges · feed ingest"] --> DB
  API --> EXT["Stripe · CRM webhooks · text-to-speech · S3"]
```

**Highlights:** every model call goes through one gateway with cost budgets and output linting · scores computed deterministically, never by the LLM · outbox-driven events · safety and isolation gates in CI.

</details>

<details>
<summary><b>TaxFiy</b>: rules-first categorisation with a RAG fallback and a cited copilot</summary>
<br/>

```mermaid
flowchart TB
  U["Self-employed workers · accountants"] --> F["Next.js · GraphQL codegen"] --> B["NestJS GraphQL API<br/>JWT · roles · plan guards"]

  B --> UP["Statements & receipts<br/>PDF text · OCR"] --> Q["pg-boss jobs"]
  Q --> RU["Rules + merchant matching"] --> RG["RAG categoriser<br/>for what rules miss"]

  GOV["HMRC / GOV.UK guidance"] --> KI["Parent–child chunking<br/>+ contextual retrieval"] --> EM["Pluggable embeddings"] --> V[("PostgreSQL + pgvector + full-text")]

  B --> CP["Tax copilot · read-only"]
  RG & CP --> RT["Hybrid retrieval<br/>RRF → rerank → parent expand"] --> V
  RT --> L["LLM"] --> CK["Citation & output checks"] --> S["SSE answer · tax estimate"]
```

**Highlights:** cheap deterministic rules before any LLM call · citations the model wasn't given are stripped · LLM-as-judge from a different model family · per-user AI cost caps.

</details>
